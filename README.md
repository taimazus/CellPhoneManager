## 📌 Overview

**CellPhoneManager v3.2.0 Royal Edition** is a high-performance, modern all-in-one desktop bridge and smartphone management suite for Windows 10 & 11 with an Imperial Charcoal & Royal 24k Gold aesthetic. It connects to Android (Xiaomi/HyperOS, Samsung One UI, Huawei EMUI, ColorOS, Google Pixel) and Apple iOS devices over high-speed USB or Wireless ADB, providing rich diagnostics, seamless hardware controls, audio streaming, screen recording, deep system cleaning, and full data management.

---

## 🌟 Key Features

* **🔊 PC-to-Phone Speaker Mode:** Ultra-low latency live system audio streaming from Windows to your connected smartphone over USB (`adb reverse`) or local Wi-Fi with an interactive mobile audio visualizer player without requiring any mobile app installations.
* **📱 Multi-OEM Package Resolver:** Intelligent package auto-detection and Android Intent fallbacks for Xiaomi (HyperOS / MIUI), Samsung (One UI), Huawei, Oppo, and Google Pixel.
* **📦 Universal Backup & Restore Suite:** 1-Click Full or Granular Custom backups for Contacts (vCard 3.0 & JSON), SMS Messages, Call Logs, DCIM Camera Photos, and Installed Apps.
* **🩺 System Doctor & Deep Junk Cleaner:** High-speed scanner to reclaim gigabytes of hidden App Cache, Temp APKs, Gallery Thumbnails, and Heavy Crash Dumps with 1-click system repairs.
* **🎥 60FPS HD Screen Recorder:** Hardware-accelerated screen recording with internal sound capture and native MP4 finalization.
* **🔬 Hardware Diagnostic Laboratory:** Comprehensive diagnostic tests including Haptic Vibration (6 real vibration patterns), Audio Synthesizer (120Hz-8kHz frequency sweeps), Full-Screen Dead Pixel RGB checker, and real-time telemetry for 23+ hardware sensors.
* **👑 Imperial Royal Theme:** Obsidian Charcoal & Royal Gold luxury theme designed for high usability and aesthetics.

## 🚀 Quick Start Guide

### 1. Clone or Download Repository
```bash
git clone https://github.com/taimazus/CellPhoneManager.git
cd CellPhoneManager
```

### 2. Launch
Double-click **`cpmStart.bat`** or run:
```bat
.\cpmStart.bat
```
The automated script validates runtime dependencies, initializes ADB/Scrcpy tools, starts the server bridge on `http://localhost:5000` / `http://localhost:3001`, and opens the dashboard in your default browser.
