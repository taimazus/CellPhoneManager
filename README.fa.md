## 📌 معرفی نرم‌افزار

**CellPhoneManager v3.4.4 Royal Edition** یک نرم‌افزار سازمانی، مدرن، پرسرعت و همه‌منظوره با طراحی لوکس سلطنتی طلایی ۲۴ عیار و زغالی آبسیدین برای رایانه‌های ویندوزی است که گوشی شما (اندروید با هر برندی یا آیفون) را به کامپیوتر متصل کرده و امکاناتی پیشرفته و تخصصی را فراهم می‌سازد:

* **📁 استودیو و اکسپلورر پیشرفته فایل‌ها (File Explorer & Studio):**
  * **درگ و دراپ پیشرفته (Drag & Drop):** امکان کشیدن و رها کردن فایل‌ها و حتی **پوشه‌های تو در تو با حفظ ساختار کامل** از ویندوز به گوشی.
  * **پابلیش و آپلود کامل:** دکمه‌های مجزا برای ارسال همزمان فایل‌ها یا آپلود یک پوشه کامل سیستم با نوار پیشرفت درصد زنده.
  * **سیستم جامع مرتب‌سازی ۸ حالته:** مرتب‌سازی دقیق بر حسب بایت (حجم بزرگ‌ترین/کوچک‌ترین)، الفبایی فارسی/انگلیسی، تاریخ (جدیدترین/قدیمی‌ترین) و پسوند (A-Z/Z-A).
  * **نمایش برجسته حجم فایل‌ها:** نمایش حجم دقیق تمام فایل‌ها با برچسب اختصاصی زمردی در تمام ۵ حالت نمایش (**ریز Compact**، **شبکه‌ای Grid**، **کارت‌های بزرگ Large**، **تایل‌های عریض Tiles** و **لیستی List**).
  * **انتخاب هوشمند و رنجی:** انتخاب با کلید `Shift + Click`، انتخاب همه، معکوس‌سازی و نوار شناور پایین صفحه.
  * **دانلود دسته‌جمعی (ZIP):** دریافت فایل‌ها و پوشه‌های انتخاب‌شده به صورت یک فایل زیپ فشرده با یک کلیک.
  * **استودیوی پیش‌نمایش چندرسانه‌ای:** پخش زنده ویدیو با کنترل‌های کامل، موزیک پلیر داخلی، نمایشگر تصاویر با زوم و چرخش ۹۰ درجه، مرور اسناد کد و متنی و نمایشگر PDF بدون نیاز به نرم‌افزار جانبی.
* **🎮 دسته بازی وایرلس سلطنتی ویندوز (PC Gamepad Engine):** تبدیل هر گوشی به دسته بازی حرفه‌ای بدون تاخیر (Latency < 2ms) با تزریق مستقیم کدهای اسکن سخت‌افزاری (Hardware ScanCode) بدون وابستگی به زبان کیبورد ویندوز (فارسی/انگلیسی)، پشتیبانی همزمان از **۲ بازیکن (Player 1 & Player 2)**، کنترل ۸ جهته مورب، جوی‌استیک آنالوگ لمسی، ویبره هوشمند هپتیک چندسطحی و شبیه‌ساز صدای کلیک مکانیکی.
* **🛡️ موتور تشخیص و ارزیابی ۵ وضعیتی قابلیت‌ها (`capabilityManager`):** بررسی لحظه‌ای پیش‌نیازها (`آماده`، `نیازمند تنظیم`، `نیازمند ابزار`، `پشتیبانی‌نشده`، `نامشخص موقت`) به همراه راهنمای تعاملی گام‌به‌گام برای رفع موانع اتصال.
* **📦 استقرار ۱۰۰٪ آفلاین بدون نیاز به اینترنت (`bin/wheels/`):** ابزارهای بومی اندروید (ADB, Fastboot, Scrcpy) به‌همراه پکیج‌های چرخ آفلاین پایتون برای محیط‌های ایزوله.
* **🔐 بکاپ با رمزنگاری نظامی AES-256 و محافظت در برابر نفوذ:** رمزگذاری پشتیبان‌های مخاطبین، پیامک‌ها، تماس‌ها، گالری و برنامه‌ها با قابلیت بازرسی پیش از بازیابی.
* **⚡ صف اجرای دسته‌جمعی و چنددستگاهی (`taskQueueManager`):** مدیریت وظایف همزمان روی چند گوشی با امکان توقف، ادامه و گزارش‌گیری مجزا.
* **📈 تله‌متری زمانی و مانیتورینگ سلامت باتری (`telemetryManager`):** ثبت سری‌های زمانی دما، ولتاژ، چرخه‌های شارژ و فضای دیسک به همراه هشدارهای هوشمند داغ‌شدن.
* **🎛️ پروفایل‌های تنظیمات و بازگشت به نقطه امن (`profileManager`):** اعمال سریع پروفایل‌های کاربری (*Gaming Pro*، *Eco Power*، *Dev Studio*) و مقایسه تفاوت‌ها (Diff).
* **🔒 گارد ایمنی فلش فریمور و رام (`firmwareGuardManager`):** اعتبارسنجی هش SHA-256 و بررسی پارتیشن‌های هدف پیش از عملیات فست‌بوت.
* **🤖 اتوماسیون‌های هوشمند اتصال (`automationManager`):** اجرای خودکار سناریوهای سلامت‌سنجی یا بکاپ به محض اتصال کابل USB.
* **🔊 بلندگوی کامپیوتر روی گوشی (PC Speaker Mode):** استریم زنده صدای سیستم با تاخیر نزدیک به صفر روی کابل یا وای‌فای با اکولایزر بصری.
* **👑 تم سلطنتی یکپارچه و بهینه‌سازی بارگذاری:** کاهش حجم باندل اولیه فرانت‌اند با معماری Lazy Loading و انطباق کامل با استاندارد دسترسی‌پذیری WCAG AA.

## ⚙️ پیش‌نیازها و راهنمای نصب گام‌به‌گام (Installation Guide)

### پیش‌نیازهای سیستمی:
- **سیستم‌عامل:** ویندوز ۱۰ یا ۱۱ (نسخه ۶۴ بیتی x64)
- **محیط اجرایی:** [Node.js](https://nodejs.org) (نسخه 18 یا بالاتر)
- **پایتون (اختیاری جهت ابزارهای تکمیلی):** پایتون 3.10+ (کلیه پکیج‌های چرخ در پوشه `bin/wheels/` به صورت آفلاین موجود است)

### مراحل نصب کامل:
1. **دریافت سورس کد (Clone):**
   ```bash
   git clone https://github.com/taimazus/CellPhoneManager.git
   cd CellPhoneManager
   ```
2. **نصب پکیج‌ها و وابستگی‌ها:**
   ```bash
   npm install
   ```
3. **تنظیم شورتکات دسکتاپ و قرارگیری در مسیر PATH (یک‌بار اجرا):**
   ```bash
   npm run setup:shortcut
   ```
   *(یا دابل‌کلیک روی فایل `setupDesktopShortcut.bat`)*

## 🖥️ افزودن به PATH و ایجاد میانبر دسکتاپ (اجرا از هر جا با دستور cpm)

برای اینکه بتوانید برنامه را با کلیک روی آیکون دسکتاپ یا با نوشتن دستور **`cpm`** در هر ترمینال ویندوز اجرا کنید:

### روش ۱: اجرای فایل خودکار نصب شورتکات (توصیه شده)
کافیست روی فایل **`setupDesktopShortcut.bat`** دابل‌کلیک کنید یا دستور زیر را در ترمینال اجرا نمایید:
```bash
npm run setup:shortcut
```
این دستور کارهای زیر را به صورت خودکار انجام می‌دهد:
1. **ثبت در PATH ویندوز:** مسیر پروژه را به متغیر محیطی `PATH` ویندوز اضافه می‌کند تا در هر خط فرمان (CMD یا PowerShell) و همچنین پنجره Run (`Win + R`) تنها با نوشتن کلمه `cpm` برنامه باز شود.
2. **شورتکات دسکتاپ با آیکون برنامه:** یک میانبر رسمی با نام **Cell Phone Manager** و لوگوی برنامه روی دسکتاپ ویندوز قرار می‌دهد.
3. **افزودن به Start Menu:** شورتکات برنامه به منوی استارت ویندوز نیز افزوده می‌شود.

## 🚀 راهنمای اجرای نرم‌افزار

### ۱. اجرای مستقیم از خط فرمان (از هر مسیر)
پس از اجرای اسکریپت شورتکات، در هر پنجره ترمینال یا Run بنویسید:
```bash
cpm
```
یا با آرگومان‌های زیر:
```bash
cpm --restart   # راه‌اندازی مجدد سرویس‌ها
cpm --stop      # بستن و آزادسازی پورت‌ها
```

### ۲. اجرای پوشه‌ای نرم‌افزار
می‌توانید روی فایل **`cpmStart.bat`** دابل‌کلیک کنید:
```bat
.\cpmStart.bat
```
این اسکریپت به صورت خودکار:
1. سرویس پس‌زمینه (Backend) را روی پورت `3001` اجرا می‌کند.
2. رابط کاربری (Frontend) را روی پورت `5173` بالا می‌آورد.
3. مرورگر شما را به آدرس `http://localhost:5173` باز می‌کند.

## 🎮 راهنمای استفاده از دسته بازی روی موبایل

1. کامپیوتر و گوشی را به یک مودم Wi-Fi متصل کنید (یا از طریق کابل USB قابلیت Reverse را فعال کنید).
2. در داشبورد نرم‌افزار به زبانه **«🎮 دسته بازی (Remote Controller)»** بروید یا در مرورگر گوشی آدرس آی‌پی کامپیوتر را وارد کنید (مثال: `http://192.168.1.152:3001/gamepad.html`).
3. دکمه **«⛶ تمام‌صفحه»** را در گوشی لمس کنید تا صفحه افقی قفل شود.
4. بازی مورد نظر (مانند **FIFA 18**، **Need for Speed** یا **PES**) را اجرا کرده و **یک بار با ماوس روی پنجره بازی کلیک کنید** تا فوکوس ورودی فعال شود.
5. برای بازی دونفره، گوشی دوم را نیز به همان آدرس متصل کرده و دکمه **«🎮 بازیکن ۲»** را انتخاب کنید.
